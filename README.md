# 🌿 TraceBack — Lost and Found Platform for Public Spaces

### 🔎 A MERN Stack-Based Digital Lost-and-Found Platform for Public Gardens and Parks

TraceBack is a digital lost-and-found platform designed to help people report, discover, and recover lost belongings in public spaces. This project adapts a digital lost-and-found concept for public gardens and parks, with a focus on the needs of visitors and garden authorities.

The project combines web development with field research conducted at selected public gardens in Mira Road (East), Maharashtra.

## 🎯 Project Objectives

- Study existing lost-and-found practices in public gardens and parks.
- Understand the difficulties faced by visitors and garden authorities.
- Assess public awareness and requirements through questionnaires and field observations.
- Develop a digital platform to support lost-item reporting and recovery.
- Explore secure item verification, claim management, and safe handover practices.

## 📍 Field Study Locations

- 🌳 Kanungo Garden, Mira Road (East)
- 🌿 Ala Hazrat Garden, Mira Road (East)
- 🌱 Public Park, Medetiya Nagar, Mira Road (East)

## ✨ Key Features

- 📦 **Lost and Found Reporting:** Report lost or found belongings with images, location details, and keywords.
- 🔍 **Smart Matching:** Help identify potential matches between lost and found item reports.
- 🛡️ **Admin Dashboard:** Support item verification, user management, and claim review.
- 👤 **User Dashboard:** View relevant statistics, potential matches, and submitted claims.
- 🔐 **Authentication and Role-Based Access:** JWT-based authentication for user and admin access.
- 🖼️ **Image Uploads:** Upload item images using Multer.
- 📱 **Responsive Interface:** Access the platform through different screen sizes.

*Feature availability depends on the current implementation; verify each feature in the running application before presenting it as complete.*

## ⚙️ How It Works

1. **Report:** A user submits details of a lost or found item.
2. **Store:** The application stores the submitted information in the database.
3. **Match:** The platform helps identify possible matches between item reports.
4. **Review:** Relevant reports and claims can be reviewed through the admin workflow.
5. **Recover:** Users can follow the claim and verification process to help recover belongings.

## 🏞️ Field Research

The project includes fieldwork at selected public gardens in Mira Road (East). The study involved public questionnaires, feedback from garden authorities, site observations, and photographs.

The findings help connect the platform’s design with the practical challenges of lost-and-found management in public spaces.

## 🔐 Security and Privacy Considerations

- Authentication and role-based access control.
- Password hashing using bcrypt.
- Request validation to help reduce invalid submissions.
- Item verification and claim review.
- Responsible handling of user-submitted information and item images.
